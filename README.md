# G2B Product Info Collector

나라장터 종합쇼핑몰의 상품 상세 정보를 엑셀 기반으로 수집하는 개인용 업무 보조 프로그램입니다.

이 프로젝트는 사용자가 준비한 엑셀 파일의 `물품식별번호` 목록을 기준으로 나라장터 종합쇼핑몰에서 상품을 검색하고, 검색 결과의 상세페이지에 접근하여 필요한 상품 정보를 정리한 뒤 결과 엑셀 파일로 저장합니다.

> 본 프로젝트는 개인 학습 및 개인 업무 보조 목적으로 제작되었습니다.  
> 조달청, 나라장터, 나라장터 종합쇼핑몰과 공식적으로 관련된 프로젝트가 아닙니다.

## 주요 기능

| 컬럼명 | 설명 |
|---|---|

| 업체명 | 계약자 또는 공급자 업체명 |
| 상세페이지링크 | 상세페이지 공유 버튼에서 추출한 링크 |
| 구성 | 상품속성정보의 구성 항목 |
| 옵션/기타 | 상품속성정보의 옵션 또는 기타 항목 |
| 처리상태 | 수집 성공, 확인 필요, 실패 여부 |
| 오류내용 | 실패한 경우 오류 내용 |

## 법적 및 사용상 주의사항

이 프로젝트는 공개적으로 접근 가능한 웹 화면을 사용자가 직접 조회하는 흐름을 자동화한 개인용 도구입니다.

사용자는 다음 사항을 준수해야 합니다.

- 서비스 이용약관과 관련 법령을 준수해야 합니다.
- 로그인 우회, 인증 우회, 보안 우회, 캡차 우회 목적으로 사용하지 않습니다.
- 과도한 반복 요청으로 대상 서비스에 부담을 주지 않도록 주의해야 합니다.
- 수집한 데이터는 사용자가 책임지고 적법한 범위 내에서 사용해야 합니다.
- 대량 수집, 재판매, 무단 배포, 데이터베이스화 등은 별도의 검토가 필요할 수 있습니다.
- 나라장터 사이트 구조, 정책, 팝업, 화면 구성 변경에 따라 프로그램이 정상 작동하지 않을 수 있습니다.

본 프로젝트는 조달청 또는 나라장터의 공식 API나 공식 배포 프로그램이 아니며, 특정 기관과의 제휴나 공식 지원을 의미하지 않습니다.

## 실행 방법

이 프로젝트는 두 가지 방식으로 실행할 수 있습니다.

1. Python 개발 환경에서 직접 실행
2. Windows 실행 파일 `.exe`로 실행

---

### 1. Python 개발 환경에서 실행하기

#### 1) 가상환경 생성

```bash
python -m venv .venv
```

#### 2) 가상환경 실행

Windows PowerShell 기준:

```bash
.venv\Scripts\activate
```

정상적으로 실행되면 터미널 앞에 `(.venv)`가 표시됩니다.

#### 3) 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

#### 4) Playwright 브라우저 설치

```bash
python -m playwright install chromium
```

단, 실행 파일 배포 버전에서는 PC에 설치된 Microsoft Edge 또는 Google Chrome을 우선 사용하도록 구성되어 있습니다.

#### 5) 프로그램 실행

```bash
python main.py
```

실행하면 GUI 창이 열립니다.

---

### 2. Windows 실행 파일로 실행하기

PyInstaller로 빌드된 실행 파일을 사용하는 경우, 아래 파일을 실행합니다.

```text
나라장터상품정보수집기.exe
```

주의사항:

- `.exe` 파일만 단독으로 빼서 실행하지 마세요.
- PyInstaller가 생성한 폴더 전체를 유지한 상태에서 실행해야 합니다.
- `_internal` 폴더를 삭제하면 프로그램이 정상 작동하지 않을 수 있습니다.

예시 폴더 구조:

```text
나라장터상품정보수집기/
├─ 나라장터상품정보수집기.exe
└─ _internal/
```

## 입력 엑셀 형식

입력 엑셀 파일은 반드시 `.xlsx` 형식이어야 합니다.

A1 셀에는 반드시 아래 컬럼명이 들어가야 합니다.

```text
물품식별번호
```

예시:

| 물품식별번호 |
|---|
| 25373089 |
| 12345678 |
| 98765432 |

주의사항:

- A1 셀에는 반드시 `물품식별번호`라는 글자가 들어가야 합니다.
- `물품식별번호`는 띄어쓰기 없이 정확히 입력해야 합니다.
- 실제 물품식별번호는 A2 셀부터 아래로 한 줄에 하나씩 입력합니다.
- 실제 물품식별번호의 자릿수는 상품마다 다를 수 있으므로, 나라장터에 등록된 번호 그대로 입력해야 합니다.
- 숫자 앞뒤에 공백이 들어가지 않도록 주의해야 합니다.
- A1 셀의 컬럼명이 다르면 프로그램이 입력 파일을 제대로 읽지 못할 수 있습니다.

잘못된 예시:

```text
물품 번호
물품식별 번호
식별번호
상품번호
```

## GUI 사용 방법

1. `나라장터상품정보수집기.exe` 또는 `python main.py`를 실행합니다.

2. 프로그램 창이 열리면 `입력 엑셀` 항목에서 [파일 선택] 버튼을 누릅니다.

3. 물품식별번호가 들어있는 `.xlsx` 파일을 선택합니다.

4. `결과 폴더` 항목에서 [폴더 선택] 버튼을 누릅니다.

5. 결과 파일을 저장할 폴더를 선택합니다.

6. [수집 시작] 버튼을 누릅니다.

7. 자동으로 브라우저가 열리고 나라장터 종합쇼핑몰 검색 및 상세정보 수집이 진행됩니다.

8. 수집 중에는 자동으로 열린 브라우저를 닫거나 직접 조작하지 않습니다.

9. 완료 메시지가 표시되면 결과 폴더에서 `result.xlsx` 파일을 확인합니다.

10. 실패 항목이 있는 경우 `failed_result.xlsx` 파일이 함께 생성될 수 있습니다.

| 컬럼명 | 설명 |

### failed_result.xlsx

수집 실패 항목만 따로 저장되는 파일입니다.

이 파일이 생성되면 `오류내용`을 확인한 뒤 해당 물품식별번호만 다시 수집하면 됩니다.

## 중복 처리 기준

같은 물품식별번호로 검색했을 때 여러 상품이 나올 수 있습니다.

이 프로그램은 같은 물품식별번호라도 상세페이지 공유 링크가 다르면 서로 다른 상품으로 판단합니다.

반대로 상세페이지 공유 링크가 완전히 같으면 중복으로 판단하여 한 번만 저장합니다.

즉, 중복 판단 기준은 다음과 같습니다.

```text
물품식별번호 같음 → 중복으로 판단하지 않음
상품명 같음 → 중복으로 판단하지 않음
업체명 같음 → 중복으로 판단하지 않음
상세페이지링크 같음 → 중복으로 판단
상세페이지링크 다름 → 서로 다른 상품으로 판단
```

## 사용 시 주의사항

- 프로그램 실행 전 열려 있는 엑셀 파일을 모두 닫는 것을 권장합니다.
- 수집 중에는 `result.xlsx` 또는 `failed_result.xlsx` 파일을 열지 마세요.
- 수집 중 자동으로 열린 브라우저를 닫지 마세요.
- 수집 중 자동화 중인 브라우저를 직접 조작하지 마세요.
- 결과 저장용 폴더를 미리 만든 뒤 해당 폴더를 결과 폴더로 선택하는 것을 권장합니다.
- 프로그램 폴더 안의 파일을 임의로 삭제하지 마세요.
- `.exe` 파일만 단독으로 이동하지 말고, 제공된 프로그램 폴더 전체를 유지한 상태에서 실행해야 합니다.
- 나라장터 사이트의 화면 구조, 팝업, 공유 버튼, 검색 결과 구조가 변경되면 프로그램이 정상 작동하지 않을 수 있습니다.

## 오류 발생 시 확인사항

### 1. 엑셀 저장 오류가 발생하는 경우

아래 내용을 확인하세요.

- `result.xlsx`가 열려 있는지 확인합니다.
- `failed_result.xlsx`가 열려 있는지 확인합니다.
- 입력 엑셀 파일이 열려 있는지 확인합니다.
- 파일 탐색기 미리보기 창이 켜져 있다면 끕니다.
- 엑셀을 모두 종료한 뒤 다시 실행합니다.
- 결과 저장 폴더를 바탕화면에 새로 만든 폴더로 지정해봅니다.

---

### 2. 브라우저가 실행되지 않는 경우

아래 내용을 확인하세요.

- Microsoft Edge 또는 Google Chrome이 설치되어 있는지 확인합니다.
- 프로그램 폴더 안의 `_internal` 폴더가 삭제되지 않았는지 확인합니다.
- `.exe` 파일만 따로 빼서 실행하지 않았는지 확인합니다.
- 제공된 폴더 전체 상태에서 실행합니다.

---

### 3. 검색 결과가 없다고 나오는 경우

아래 내용을 확인하세요.

- 입력한 물품식별번호가 정확한지 확인합니다.
- 숫자 앞뒤에 공백이 없는지 확인합니다.
- 엑셀 A1 셀에 `물품식별번호`라는 컬럼명이 정확히 들어가 있는지 확인합니다.
- 나라장터 종합쇼핑몰에서 직접 검색했을 때 결과가 나오는지 확인합니다.

---

### 4. 구성 또는 옵션/기타가 비어 있는 경우

아래 가능성이 있습니다.

- 해당 상세페이지에 실제로 상품속성정보가 없는 경우
- 나라장터 화면 구조가 변경된 경우
- 일시적으로 상세페이지 로딩이 제대로 되지 않은 경우

이 경우 `result.xlsx` 또는 `failed_result.xlsx`의 `처리상태`, `오류내용`을 확인하세요.

---

## 제한사항

- 사이트 구조가 변경되면 일부 selector가 작동하지 않을 수 있습니다.
- 팝업 종류가 변경되면 팝업 처리 로직 수정이 필요할 수 있습니다.
- 공유 버튼 구조가 변경되면 상세페이지 링크 추출이 실패할 수 있습니다.
- 인터넷 연결 상태나 사이트 응답 속도에 따라 일부 항목이 실패할 수 있습니다.
- 대량 수집 시 대상 서비스에 부하를 줄 수 있으므로 사용량을 제한해야 합니다.

## 배포 시 주의사항

Windows 사용자에게 전달할 때는 실행 파일만 단독으로 전달하지 말고, PyInstaller가 생성한 폴더 전체를 압축하여 전달해야 합니다.

예시:

```text
나라장터상품정보수집기/
├─ 나라장터상품정보수집기.exe
└─ _internal/
```

권장 압축 파일명:

```text
나라장터상품정보수집기.zip
```
